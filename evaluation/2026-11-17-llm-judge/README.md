# 국가유산 관련 지식 응답: LLM-as-a-Judge 평가

- 심사 모델: `gemini-3.5-flash-lite` (호출 응답의 `modelVersion`도 저장)
- 평가 대상: 기존 국가유산 지식 질문 100문항 × Qwen/HyperCLOVA 학습 전·후 = 400개 저장 응답
- 대상 모델 재추론 없이 기존 응답을 재채점한다. GPU를 사용하지 않는다.
- 심사 입력: 질문, 기준 정답, 근거 사실, 대상 응답. 모델명·학습 단계·파일명·내부 식별자는 전송하지 않는다.
- 정답: 질문의 핵심 사실 모두 충족. 동의어·의역·숫자와 한글 수사·동등한 단위 표현을 인정한다.
- 부분 정답: 복수 핵심 요구사항 중 일부만 충족.
- 오답: 핵심 사실 오류·누락, 회피, 무응답, 핵심 답과 충돌하는 주장.
- 판정 불가: 기준 정답/근거의 모순 등으로 채점 근거가 부족한 경우.
- 주요 지표: LLM 판정 정답률 = 정답 판정 건수 / 전체 100문항 × 100. 부분 정답 및 판정 불가도 분모에 유지한다. 범주별 건수와 동일 문항의 개선·회귀를 함께 보고한다.
- 질문의 이미지 자체는 심사 모델에 제공하지 않는다. 이 평가는 기준 정답·근거에 대한 응답의 의미적 정합성을 평가한다.
- temperature=0, 최대 출력 4096토큰, 독립 문항별 호출. 최종 집계는 최초 유효 판정으로 고정하며 재판정으로 유리한 결과를 선택하지 않는다.
- 사전 검증: 정답/의역/오답/부정/양립 불가능한 답/부분 정답 등을 포함한 인위적 예시 10건. 평가 대상 400개와 별도이다.
- 재판정 검증: 각 모델·단계에서 고정 시드로 10건씩 총 40건을 선정하여 동일 모델로 재호출. 네 범주 일치와 정답 여부 일치를 구분해 보고한다. 이는 사람과의 일치도와 다르다.

## 실행

표준 Python만 필요하다. 키는 출력·결과 파일에 저장하지 않는다.

```bash
export GEMINI_API_KEY='본인의 API 키'
python run_judge.py --phase calibration
python run_judge.py --phase main
python run_judge.py --phase repeat
python summarize_judge.py
```

또는 `--env-file /path/to/.env`로 `GEMINI_API_KEY`를 읽을 수 있다. 실행 중단 시 같은 명령으로 완료된 판정을 건너뛰고 재개한다.

`*_manifest.json`에 실제 프롬프트·생성 설정·원본 파일 해시를, `*_results.jsonl`에 판정 근거·원본 API 응답·모델 버전을 저장한다. `private_mapping.json`은 내부 식별자와 평가 모델·단계의 대응표이며 심사 모델에 전송하지 않는다. `summary.json`과 `judgments_joined.jsonl`은 최종 집계 및 문항별 추적 자료이다.

심사 모델도 오류와 편향이 있을 수 있으므로 결과는 LLM 자동 판정으로 명시한다. 핵심 사실의 사람 검증 및 독립 이미지 근거 평가는 별도 검증이다.
