# 공개 이력 구성

이 저장소는 기존 로컬 코드와 실험 산출물을 개발 의존 순서에 따라 **150개 커밋으로 재구성**한 최초 공개본이다. 과거 개발 시점의 실제 Git 이력을 복원한 것이 아니며 커밋 시각을 소급하지 않았다. 커밋은 모두 실제 파일 변경을 포함한다.

순서: 저장소 안내와 환경 → 모델 실행 → 공통 SFT 구현과 데이터 처리 → 27B·32B 학습 설정 → 변환·배포 도구 → HAECHI 평가 → 결과와 분석서 → 공개 검증.

`SOURCE_MANIFEST.json`은 복사 원본의 SHA-256과 공개본의 SHA-256을 기록한다. 경로 이식, 실행 환경 준비 등의 수정은 두 해시의 차이로 확인할 수 있다. 데이터·응답·측정 결과 원본은 재생성하거나 개선된 값으로 교체하지 않았다.
